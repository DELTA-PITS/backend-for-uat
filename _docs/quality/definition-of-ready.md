# Definition of Ready

Checklist ini dijalankan di akhir Fase 2B (Requirement Review), sebelum requirement dianggap siap masuk Technical Design (Fase 3B). File tetap — bukan per-fitur.

- [ ] User story + acceptance criteria lengkap dan testable
- [ ] Semua open question sudah dijawab stakeholder — bukan diasumsikan AI
- [ ] Trade-off teknis (kalau ada >1 opsi viable) sudah didiskusikan & diputuskan, dicatat di BRD atau ADR terpisah
- [ ] Dependency eksternal (Keycloak realm, Anvil, kredensial) sudah dikonfirmasi TERSEDIA — bukan "kemungkinan ada"
- [ ] Tidak ada blocker yang diketahui tidak bisa diselesaikan dalam estimasi
- [ ] Requirement sudah di-approve
